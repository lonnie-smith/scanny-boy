# Punchlist

Unscheduled, unimplemented items. Each names its attachment point so that
whoever picks it up knows where the work lands. See also `docs/DECISIONS.md`
for the decisions that superseded earlier items.

## Colour

* **Generate the intermediates' ICC profile per camera** from
  `camera_color.rgb_xyz_matrix` — the sensor's real primaries with a linear
  TRC — which would make that one profile fully true rather than merely
  honestly labelled (docs/PROFILE_HONESTY_PLAN.md §7). It only half-helps
  the published TIFF: its primaries would become true, but its TRC is
  normalized log density, which no ICC TRC expresses, and the per-channel
  normalization has moved its effective white point. It also converts two
  bundled build-time constants into runtime-generated bytes. Attachment
  point: `probe.py`'s invariant seeding (plus `pipeline.py` and
  `stitch_pipeline.py`, the `generate_icc_profile.py` tool, and the
  packaging tests that enumerate bundled resources).
